# 📄 EML Processing Flow

Uploaded `.eml` files are parsed to extract hidden email metadata.

```text
EML Upload
    |
    v
Extract Headers
    |
    +----------------------------+
    |                            |
    v                            v
SPF Validation            Sender Analysis
DKIM Validation           Subject Extraction
DMARC Validation          Timestamp Extraction
    |
    v
Header Mismatch Detection
    |
    v
Risk Score Calculation
```

The following security indicators are inspected:

- SPF authentication status
- DKIM authentication status
- DMARC policy status
- Sender spoofing attempts
- Header inconsistencies
- Suspicious URLs
- Social engineering language

# 📐 Image Highlight Spatial Scaling

Bounding boxes generated by EasyOCR use the original image dimensions. Since the frontend image size changes depending on screen size, scaling calculations are required.

## Scaling Factor Calculation

```text
Width Scale Ratio
= Rendered Image Width / Original Image Width

Height Scale Ratio
= Rendered Image Height / Original Image Height
```

## Render Formula

```text
Rendered X Position
= Original X × Width Scale Ratio

Rendered Y Position
= Original Y × Height Scale Ratio

Rendered Width
= Original Width × Width Scale Ratio

Rendered Height
= Original Height × Height Scale Ratio
```

This ensures highlighted threat regions remain accurately aligned even when the browser window is resized.

# 📊 Risk Assessment Engine

Threat scoring uses a heuristic-based cumulative scoring model.

| Threat Signal | Risk Points |
|---------------|------------|
| Urgency Indicators | +30 |
| Credential Requests | +30 |
| Fear Tactics | +20 |
| Suspicious URLs | +15 |
| Header Mismatch | +25 |
| Failed SPF/DKIM/DMARC | +20 |
| QR Code Redirects | +15 |

The maximum possible risk score is capped at:

```text
100 / 100
```

# 🧠 Threat Intelligence Output

After analysis, the backend returns a structured JSON object containing:

- Risk Score
- Severity Level
- Threat Reasons
- Extracted URLs
- Header Findings
- OCR Content
- Recommended Actions
- Scan Metadata

This response is rendered into the interactive threat intelligence dashboard.
