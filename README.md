# Email Phishing Analyzer

## Overview

Email Phishing Analyzer is a cybersecurity tool that helps identify potentially malicious emails through:

* Email header analysis
* SPF, DKIM, and DMARC validation
* URL inspection
* Content analysis
* Risk scoring

## Features

* Upload EML files
* Paste email content
* Analyze suspicious URLs
* Generate phishing risk scores
* Explain detected indicators

## Tech Stack

### Frontend

* React
* Tailwind CSS

### Backend

* FastAPI
* Python

### Analysis

* EML Parsing
* URL Analysis
* Content Analysis
* OCR (planned)
